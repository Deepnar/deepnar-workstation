# INSPIRATION — principles only, no cloning

What navigation-itself-memorable means for a Linux workstation (not a car).

## 1. Bruno Simon — bruno-simon.com (3D driving portfolio)
- Principle: the *first interaction* teaches the world (drive to discover). Ours: boot → greeter → open the one app; each step teaches the next.
- Principle: discoverability through proximity (drive near things). Ours: `cd` into directories, hover states, pet inspecting newly opened panes.
- Principle: options panel (sound/quality/respawn) always reachable, never blocking. Ours: compact settings popover.
- Anti-lesson: weakest scores were usability/accessibility — we keep mouse-first, skip-link, reduced-motion, contrast.

## 2. Classic terminal portfolios (the good ones)
- Principle: every displayed shortcut works. If `f` is printed, `f` must fire.
- Principle: `help` is a real command with real output, not a tour.
- Anti-lesson: most are a single fake prompt over card grids — V1's trap. V2: one filesystem behind every surface.

## 3. Fake-OS portfolios (the trap genre)
- Principle worth stealing: spatial memory (things live *somewhere*: desktop → window → file).
- Anti-lesson: calculator/minesweeper/trash/settings-app clutter kills credibility. One workstation app only.

## 4. Neovim + LazyVim startup screen
- Principle: centered, sparse, key-aligned rows (`Find file   f`); recent files as memory.
- Principle: everything is a buffer; `:e`, `:bd`, `:bnext` compose.

## 5. Telescope / fzf
- Principle: one finder over files + commands + history with path · type · recency metadata and fuzzy highlight.
- Principle: preview follows selection.

## 6. lazygit / btop
- Principle: dense flat rows, 1px divisions, selected-row highlight — no cards.
- Principle: status segments carry state (branch, mode, context) at a glance.

## 7. Codex / Claude Code terminal UIs
- Principle: agent activity as staged checklist (◇ working → ◆ done), fast, dismissible.
- Principle: context chips (`ctx ~/projects/ice`) make narrow retrieval feel smart.

## 8. Linux greeters (GDM/SDDP minimal themes)
- Principle: clock + name + one button; no fake password field. Session label ("read-only") sets fiction honestly.

## 9. Hyprland rice showcases
- Principle: motion is orientation (scale 0.92→1, 20–40px slides, 180–280ms), never decoration.
- Principle: active border is the only glow; wallpaper is calm procedural space.

## 10. Game-feel microinteraction (Vlambeer-style, restrained)
- Principle: tiny confirmations (tick, relay click) make UI feel physical. Sound like punctuation, never prose.
