# Cursor artwork attribution

All `*.png` files in this directory are renders of the
[catppuccin/cursors](https://github.com/catppuccin/cursors) theme
(`catppuccin-latte-lavender-cursors v2.0.0`), scaled 24 → 32px with
hotspots preserved from the theme's `metadata.json`.
